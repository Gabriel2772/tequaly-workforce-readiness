# TWR Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o fluxo ponta a ponta de cadastro sintético, operação, elegibilidade determinística e comparação dos três cenários otimizados.

**Architecture:** Um backend FastAPI modular concentra domínio, serviços, repositórios e OR-Tools; PostgreSQL é a fonte de verdade. Um frontend Next.js App Router consome somente a API. O candidate pool é filtrado antes do CP-SAT e cada execução gera um `DecisionRun` auditável.

**Tech Stack:** Python 3.12, FastAPI, Pydantic 2, SQLAlchemy 2.0, Alembic 1.18, PostgreSQL 18, OR-Tools CP-SAT, pytest, Next.js App Router, React, TypeScript, Tailwind, Vitest e Playwright.

## Global Constraints

- Node.js `>=20.9`; Python `3.12`; PostgreSQL `18.x`.
- Não existe entidade `Evidence`.
- Não existe integração com Tequaly Field Intelligence ou RAG.
- Elegibilidade e otimização não dependem do LLM.
- Nenhum requisito obrigatório pode ser relaxado pelo solver.
- O seed principal contém 2.200 colaboradores fictícios e o benchmark contém 3.000.
- O `EmployeeProfileVector` começa por `cargo_funcao_principal`, `nome`, `qualificacoes`.
